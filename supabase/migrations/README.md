# Migrations

Every file here has **already been applied to production** (via the Supabase
Management API) and was recorded afterwards — they are transcripts, not a queue.
Order is the `YYYYMMDD_` prefix (same-day files are independent unless the
header says otherwise). First line of each file: `-- <purpose>. Applied live <date>.`

Files dated before 2026-08-31 lived at the repo root until 2026-09-10; they were
moved here unchanged, prefixed with the date they were applied.
